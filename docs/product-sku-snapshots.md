# 稳定 SKU 与订单权益快照

更新日期：2026-10-26（Asia/Shanghai）。商品现可配置唯一 SKU 和订阅月数；两者对既有演示商品均为可选。首次设定的 SKU 不可修改或清空，防止同一编码在不同商品间改义。建议首批月度套餐分别使用 `CHATGPT_GO_MONTHLY`、`CHATGPT_PLUS_MONTHLY`、`CHATGPT_PRO_MONTHLY`；这里只约定编码，不创建真实商品或启用真实销售。

钱包购买与卡密兑换共用建单流程。新订单会保存下单时的商品名称、SKU、说明、订阅月数、金额和是否要求逐项核验。后续修改商品资料不会改写历史订单。管理后台「订单管理 → 下单权益」可查看快照；迁移前的旧订单只保留原来已有的名称、金额与商品 ID，新字段显示“历史订单未记录”，不会用当前商品资料倒填。

SKU 只标识平台内部商品，不证明 Go、Plus 或 Pro 已有正式销售或开通渠道。正式上架前仍要逐项确认实际权益、地区、价格、履约和退款规则。
