## 建议验收顺序

1. 使用验收管理员登录，进入「管理后台」→「监控与告警」。检查履约worker和monitor近期心跳；邮件功能默认关闭，因此邮件worker可显示当前不要求运行。
2. 在告警状态选择「已恢复」，查看`worker心跳异常 / 履约worker`。本次真实停止worker并重启，已记录首次触发和自动恢复事件；可打开事件记录核查。
3. 进入「运行状态」，查看模式/等待阈值/队列摘要，按异常分类查订单。不要将无异常提示当作外部服务或资金健康证明。
4. 进入「商品套餐」，可新建一件低价演示商品，再用普通注册账号演示充值和购买。后台与代理定价、采购金额确认、角色权限均沿用原功能。
5. 进入「统计报表」，按今天UTC日期/钱包来源/商品ID筛选，核查成交、退款、净额并下载CSV。退款按原订单创建日归集，净额不是利润。
6. 进入「操作日志」，选择日期、精确操作类型或目标ID查询，打开详情并导出CSV；导出自身会写审计，重新查询才会看到新的日志。
7. 卡密生成时立即下载TXT/CSV，之后只保留哈希，无法重新导出完整卡密。公开兑换会返回订单编号和独立查询凭证，请妥善保存。

监控确认只表示管理员已安排跟进，不会替你重试/退款。仅在规则恢复后自动进入已恢复；复发重新打开并增加轮次。老页面的轮次不符会拒绝确认，避免误确认新一轮异常。
