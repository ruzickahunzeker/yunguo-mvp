# 订单状态矩阵（当前演示实现）

本矩阵描述钱包购买和公开卡密兑换的本地状态机。它不代表真实支付渠道或外部订阅已经接入。

| 支付状态 | 履约状态 | 允许动作 | 退款 | 说明 |
|---|---|---|---|---|
| `PAID` | `QUEUED` | `complete`、`fail`、`cancel` | 钱包订单可在取消后退款 | worker 或管理员处理；逐项核验商品必须先完成四步核验 |
| `PAID` | `PROCESSING` | `complete`、`fail` | 失败后人工退款 | 预留给外部履约；当前 mock worker 不停留在此状态 |
| `PAID` | `FAILED` | `retry`（最多 3 次执行）或 `refund` | 钱包订单可退款 | 退款后不可重试；卡密订单不走钱包退款 |
| `PAID` | `CANCELED` | `refund` | 钱包订单可退款 | 取消只允许发生在 `QUEUED` |
| `PAID` | `COMPLETED` | 无普通动作 | 不自动退款 | 已完成/已开通需人工核验 |
| `REFUNDED` | 任意终态 | 重复 `refund` 幂等返回 | 不重复入账 | 固定流水引用 `refund:<order_id>` |

补充规则：

- 卡密兑换订单金额为 0，不扣代理或用户钱包，也不自动恢复库存。
- 每次动作都写订单事件和管理员审计；非法状态转换返回 409。
- 订单、履约任务和钱包流水在同一事务内更新；并发退款由订单锁和唯一流水引用保证只入账一次。
- 真实支付接入后必须增加渠道支付状态、原路退款、拒付和对账状态，不能直接复用演示钱包状态。
