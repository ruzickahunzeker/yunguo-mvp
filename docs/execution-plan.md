## 推荐执行顺序

1. 先完成 P0-01、P0-02、P0-05，确认 Go、Plus、Pro 的商品和售后规则。
2. 录入 P0-03 的价格后，分别验收零售用户、代理默认价、等级价和专属价。
3. 完成 P0-04 的演示回归和 P0-06 的 GitHub 门禁。
4. 取得支付资料后执行 P1-01；取得正式授权服务商资料后执行 P1-02、P1-03。
5. 完成 P1-04 和 G-01 至 G-05，才讨论生产发布。

每完成一项，都在 `docs/verification.md` 记录命令、环境、结果和限制；没有证据的任务保持“待执行”或“进行中”。
