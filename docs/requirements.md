## 工程默认假设

- 单币种 CNY，所有 API 金额为整数分，0 元商品允许；充值必须正整数。
- 演示余额没有真实货币价值，不可提现。生产强制关闭演示充值。
- 钱包购买立即完成付款，只有 PAID/REFUNDED；不创建没有支付途径的待付款订单。卡密代表预付权益，兑换订单金额为0，不计钱包收入。
- 公开兑换无需注册，兑换订单不强行绑定当前用户；独立查询凭证承担持有者授权。不能只凭订单号查询。
- 卡密在生成时预留库存，兑换时不二次扣库存。废卡/到期/取消/退款不会自动加回库存，须人工核实。
- 代理按指定代理价、等级价、默认 `agent` 价、零售价依次解析，管理员按零售价购买。库存卡密由管理员分配，原始卡密由其安全交付。
- 模拟履约由数据库队列原子完成；人工失败后需管理员决定重试或退款。当前不对接外部资源，worker 不会开通真实订阅。
- 已完成订单和卡密订单不提供自动钱包退款；失败/取消的钱包订单可退款。卡密售后需核实实际收款/交付，不能凭卡密兑换记录自动发放资金。
